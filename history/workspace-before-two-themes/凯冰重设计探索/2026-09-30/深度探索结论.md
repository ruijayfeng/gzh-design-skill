# 凯冰排版：第二轮深度探索

日期：2026-09-30。状态：研究与局部结构实验；不是新定稿，不替换正式主题。此次新增检视 9 个中文／日系及独立刊物案例，另检查 LifeWear 官方长文页面，并由另一研究 agent 反向审查“这些原则是否真的构成个性”。

最新制作进展：用户已选择“紧凑承接”，并要求文章图片统一微圆角、铺满内容宽度。已制作[紧凑承接V1](紧凑承接-v1/凯冰_紧凑承接_预览.html)与[独立图文示范](紧凑承接-v1/图文示范_预览.html)，具体规则见[图片规范与交付说明](紧凑承接-v1/图片规范与交付说明.md)。下文的“中文主场优先”等判断保留为历史研究，不再作为当前主推方向。

## 最新约束：图文内容优先，风格不喧宾夺主

用户补充：日常文章通常包含文字和图像，希望读者专注文章内容，排版风格不应喧宾夺主。这是后续方案的首要评判标准，优先于“章首是否醒目”或“样张是否像设计作品”。

- 设计目标：有辨识度、明亮、有文气，同时让文章连续被阅读。不把内容优先误解为撤掉宋体、全部灰黑或消除用户喜欢的语义章节。
- 章节：首先帮助读者定位内容。语义英文可保留，但不要求每章都有巨大英文，也不让章首独占一屏；字号和留白须放进真实图文长文判断。已有局部实验的 52–60px 英文仅是实验参数，不是下一版默认值。
- 正文：保持稳定的字体、行距和边界，不逐段强制上色、划线或装入卡片；长正文的连续阅读比组件展示更重要。
- 图像：原文图片是内容，不是装饰。照片、截图和图表保留原内容、比例与顺序，不为风格统一而裁切、加滤镜或重绘。按最新用户要求，全部同宽铺满正文列、统一6px微圆；小源图提醒清晰度风险，不自动改成另一种窄图样式。
- 图文关系：遵守原文顺序与既有解释关系，避免在相邻文字、图片、原有图注之间插入装饰章首、色面或过大空白。图注只排原文已有内容，不编造。
- 引语与色面：居中引语可以保留，但不为每章制造停顿。原文已有图片会自然改变页面密度；彩色引语须考虑它与附近图像的竞争，不单独追求视觉高潮。
- 验证：下一步需要实际含图的原文样张，而不只看纯文字章首。重点检查连续正文、文字转图片、图片回正文及多图段；评价读者是否容易理解和继续阅读，不以“多少种组件”衡量完成度。

下文保留案例观察与上一阶段实验，作为研究记录；其中强章首和色面方向均须按本次约束重新取舍。当前纯文字实验不足以证明图文方案成立。

## 这轮真正改变的判断

上一轮 A「彩色专题」有明亮感，但还没有回答凯冰自己的文字关系是什么；B「黑字实验刊」改变更多，却离用户喜欢的宋体、语义大字和舒适对齐更远。因此，不再把 A 的配色升级当作主要答案，也不主推 B。

目前最值得深挖的命题是：**中文原题有足够表达，语义英文与它形成紧密章首；居中引语成为另一种稳定的阅读停顿。** 明亮色彩可以大胆出现，但必须依附这些文字关系，而不是每段都套一个彩色组件。

这仍是设计假设。“固定边界＋宋体＋英文＋居中引语”只是编辑风格的共性；仅靠这些，不能宣称已经建立凯冰独立识别。真正要固定的是相对尺度、组内间距、章首到正文的距离、引语的有效宽度，以及它们在不同文章中反复出现的关系。

## 哪些新参考最有用

### 1.《设计师的英语账》：英文需要有任务，颜色可以很强

LABORATORIES 官方展示的章节页由 Phase、数字、define、日文释义组成，各项都指向章节内容；蓝、珊瑚红、白构成清楚的角色。封面的大英文与章内英文并不是同一档字号。主 agent 也实际核查了封面与 Phase 1 / define 跨页。[设计师官方作品](https://www.labor-atories.com/works/デザイナーの英語帳__灰色ハイジ/)

对凯冰的推论：保留有意义的大英文，不固定成品牌缩写。把颜色集中到有必要的章节进入或原文引语，可以比只加短线更有力度。不能直接搬邮封条纹、专用模板字和纸本对页。

### 2.《新世代编辑者档案》：明亮与居中衬线并不冲突

官方作品中，鲜亮的拼色封面与 TISSUE Inc. 白底内页形成对照；内页的居中衬线题头、细横线和局部红棕色信息块分别承担不同工作。[设计师官方作品](https://www.labor-atories.com/works/新世代エディターズファイル/)

对凯冰的推论：用户喜欢的居中和宋体应继续作为积极表达，不需要为个性化而撤掉。章节、引语和正文的力度可以相差很大；不同力度并不要求容器左右错位。

### 3. Sociotype Journal：大而较轻的衬线字同样有力量

官方说明第一期使用 Gestura 衬线家族；实物图与翻阅动图展示了大标题、密集正文、小导航之间的尺度差。[Sociotype 官方第一期](https://new.socio-type.com/shop/sociotype-journal/the-gesture)

对凯冰的推论：不应把“个性更强”简单等同于字更黑、更粗。宋体的线条、标题所占的面积、行数和留白都可以产生表现力。不能指望 Georgia／系统宋体复现它的专用字形。

### 4. Works That Work 与 PAR：变化应由文章职责解释

Works That Work 的设计者说明以固定标题语言兼顾直接信息与视觉叙事；公开内页也能看到不同开场密度。PAR 官方说明则把内容分成开演前、上半场、中场休息、下半场、Bravo 五种功能。PAR 的公开内页证据不足，这里只借内容组织，不推断其具体内页样式。[Works That Work 设计者项目](https://carvalho-bernau.com/wtw1-2/)、[PAR 改版官方说明](https://odotoo.com/Par-Magazine-Identity-Redesign)

对凯冰的推论：问题进入、方法展开、原文引语、结尾收束可以不同强度，但不能随机给每章换皮肤，也不应先编 START／PAUSE／BRAVO 再往文章上套。

另检视王志弘《黑雨》、IDEA 407、Circular 19、Eye 96/97；具体观察、出处与不可迁移的部分见[中文／日系案例](中文与日系案例研究.md)和[独立刊物案例](独立刊物案例研究.md)。额外排除三例：依赖印刷图像的 NO MAGIC IN RISO、重叠图形与长列文字的 Four Quartets、内页证据不足的现代短歌 Classics。

## 公众号适配：纸本漂亮不代表手机可用

LifeWear 官方 Coco Capitán 长文页面用很大的衬线题名与小号问答正文形成对比。此次在 390px 浏览器视口中，页面仍呈现缩小的双列；因此它可以作为字体角色的参照，不能当作已验证的手机阅读母版。没有进行真实手机或公众号编辑器测试。[官方文章页面](https://www.uniqlo.com/us/en/contents/lifewear-magazine/archives/25ss/hello-coco/)

当前凯冰正文规格若在 390px 容器两侧各留 22px，正文宽约 346px，17px 中文约容纳 20 个全角字位；在 320px 容器约为 16 个。这里只是几何估算，不是最佳行长的实验结论。双语并列、深缩进卡片都会进一步压缩中文空间。

W3C《中文排版需求》把字体字号、行长、行距和字距列为版心因素，并讨论段末只剩一个汉字的孤字问题。该文目前是工作中的 Group Note Draft，不是公众号规范；书刊经验不能直接换算成手机最佳参数。排版可以调整尺寸和自然分组，不能借消除孤字改写原文。[W3C 中文排版需求](https://www.w3.org/TR/clreq/)

公众号排版 Skill 对本次研究的影响：文章内部的设想尽量采用正常文档流、内联样式、系统字体，不依赖绝对定位、裁字、外部字体或插图。实验页的外壳用于对照，不是可复制公众号正文；其中双列尤其需要后续单独验证。用户的 IP 形象始终只用于理解气质，没有进入小样。

## 已做的文字关系实验

[打开实验页](文字关系实验.html)。三项共用颜色、字体与原文段落，以便看清结构变化，不把配色差异误认为结构优劣。

| 实验 | 具体关系 | 当前取舍 |
|---|---|---|
| 双语对读 | 英文和中文并列在同一章首，固定外边界 | 短题名醒目；长题名被窄列拆碎，不作为全篇默认 |
| 中文主场 | 完整中文题名在上，强语义英文紧随其下，共用居中轴线 | 优先验证；保留既有审美，但不能只靠交换上下顺序认定独立性 |
| 紧凑承接 | 英文缩为语义索引，中文章题靠近正文 | 用来研究普通章节／小节的密度，不取代所有大语义字 |

另加入同一句原文引语的纸面居中与蓝色面居中对照。它们检验的是停顿力度，不要求所有引语都铺满颜色。

在当前 Mac 浏览器环境，实验页检查了 320、390、430px 视口。320px 双语并列中的 Value 初稿轻微超出自身列宽，已从 52px 调整到 48px；复检没有页面或被检查文本容器的横向溢出。截图确认中文主场与并列章首的实际样貌。**不溢出不等于断行优美**，长题名窄列问题仍是保留的反例；系统宋体在其他设备上的表现也未验证。

## 下一版应具体固定什么

以下是此前纯文字实验的待测试参数，不是永久主题规则；最新“图文内容优先”约束下，不直接将这些尺度作为下一版默认值：

- 主章首：中文 30–32px，语义英文约 52–60px；标题组内约 12px 空间，组外到正文约 28px。原题不改字，长题名自然断行，英文完整保留；长词另设稳定档位，不逐词任意缩放。
- 中文题名：优先保持完整表达。如果原题确有“铺垫：主判断”等结构，可测试两级字组；没有结构就整题排，不凭设计需要补副标题。
- 引语：居中宋体约 22px，行距约 1.85，上下约 40px 留白，文本宽度接近正文。纸面是常态，明确色面只给原文真正重要的少数停顿；不增加新的金句。
- 正文：保持同一宽度和稳定的 17px／约 1.95 行距。取消“每段都必须标一到三处”的机械强调设想，只在原文确有重点时处理。
- 层级：原文 `##` 与 `###` 的层级保持清楚。可以调整同层章首密度，但不能为了起伏，把小实验升成大章，或让不同视觉力度伪装成不同语义层级。
- 配色：当前实验统一蓝白是控制变量，不是最终克制配色方案。蓝／珊瑚红／暖黄仍可继续测试实际面积与职责；不能为了配齐五色而五色同时上场。

最终识别不能只在一篇短样张里成立。应在观点长文、方法教程、真实案例三种原文上检验同一标题关系；拿掉颜色再看是否仍成立，恢复颜色后再看是否明亮有力。只有这样的整篇验证与公众号实际粘贴检查完成，才适合扩成常用组件库。

## 本轮的结论与边界

继续探索“明亮、有文气、内容优先的图文编辑排版”，将中文章题、必要的语义英文、居中引语放回真实图文文章中验证。原文图片是内容；凯冰人物参考图仍不插入文章。不会用巨大 K·B、黑体化或随机错位充当个性，也不会为了风格效果让内容阅读退居其次。

本轮完成了案例研究、反方审查和局部结构实验。尚未完成新主题、完整文章排版、跨设备字体验证或公众号粘贴验证；没有覆盖旧文件、修改主题登记或推送代码。
