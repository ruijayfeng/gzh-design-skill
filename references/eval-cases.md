# 回归用例

维护 SKILL、主题或脚本后，用本页核对行为。

## 应触发

- “用词员外风格排版这篇文章：article.md”
- “用凯冰风格排版这篇文章：article.md”
- “用橄榄手记排版下面的公众号文章”
- “把这篇 Markdown 转成可粘贴到公众号的 HTML”
- “按这张参考图定制一套新的公众号排版主题”

## 不应触发

- “写一篇公众号文章”——交给写作 skill。
- “帮我润色这篇文章”——交给编辑 skill。
- “给文章生成配图”——交给图像 skill。
- “做一个网页落地页”——交给网站能力。

## 主题路由

- 指定“词员外 / 现代水墨 / 默认风格” → `theme-ciyuanwai.md`，不提问。
- 指定“凯冰 / 凯冰内容风格 / 明亮编辑 / 清新编辑 / 留白叙事 / 主 IP 风格” → `theme-kevinbee-editorial.md`，不提问。
- 指定“橄榄手记 / 编辑手记母版 / 定制母版” → `theme-olive-journal.md`。
- 未指定主题 → 默认词员外，不提问。
- 要全新风格 → 读 `theme-generator.md`。

## 内容边界

- [ ] 标题、正文、数字、标点、段落顺序和图片顺序原样保留。
- [ ] 不新增导语、摘要、目录、金句、结论、作者介绍或 CTA。
- [ ] 原文没有署名、FAQ、总结时，不生成对应组件或占位符。
- [ ] 除操作提示外，凯冰可按已授权设计添加准确对应原章内容的短语义词，不用KB，不硬套Start，不改原标题。
- [ ] 凯冰参考插画不进入新模板、预览或正文。
- [ ] 每张原图都保留，不生成、不修改、不裁切。

## 组件行为

- [ ] 同一逻辑组连续 3 张以上图片使用横向滑动组。
- [ ] 两张前后对照不横滑，使用对照组件。
- [ ] 超过约 12 行或 500 字的 Prompt、记录、补充材料使用定高滚动窗。
- [ ] 普通正文、关键结论和连续论证不放进滚动窗。
- [ ] 代码块每行一个 `<p>`，不使用 `white-space:pre`。

## 可验证循环

1. `python3 scripts/component_lint.py .` → `0 ERROR`。
2. 用 `assets/sample-article.md` 生成一篇干净正文 HTML。
3. `python3 scripts/validate_gzh_html.py <正文.html>` → `0 ERROR`。
4. 打开预览页，验证复制按钮、横向滑动和内部纵向滚动。
